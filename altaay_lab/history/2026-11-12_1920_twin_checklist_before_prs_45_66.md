Written 2026-11-11 ET. Updated 2026-11-12 ET after PRs 34 to 43 merged, and again the same day for the structure row (history/2026-11-12_0906_shin_eye_margin.md). The pass line of each row is unchanged. A row below is the reading of the merged files on that date. The 2026-11-11 wording is in the history file for this update.

Gate 0 passes only when every row below is PASS and the rows describe one duck. A sim pass only, a calc only,
or a CAD check only result is evidence. It is not a PASS of the row. An FEA pass only result is the same kind of evidence.

The duck is not printed, the pack is not welded, and the full order is not placed before this checklist is all PASS. Today it is not.

Characterization coupons are allowed, and only after Ahmed says yes. A row that needs a measurement names the coupon. For the pins that is TEST_PLAN.md 20.1 to 20.4: a few pins, a scrap of cloth, and a scrap of felt. No whole duck. The coupon is not the product and it is not the one-click bill. It exists so a guess in this list can be replaced by a measurement.

How to update a row: change the status word, the labeled result, the guess, and the next action together.
Leave the old wording in a new history file. Do not edit this file's history by silent overwrite of a result
that was wrong; write the new result in the row and say what changed.

Status words, only these:

- PASS: the pass criterion is met for the duck that will be built.
- FAIL: a run or a check exists, and it does not meet the criterion.
- NOT RUN: the check is defined and has not been executed.
- GAP: the model, the part, or the file that would hold the check does not exist yet.
